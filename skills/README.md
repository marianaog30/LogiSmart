# Skills operativos de LogiSmart

Dos carpetas versionadas con SKILL.md: `logismart-cotizar` y `logismart-revisar`. El adaptador `scripts/hito7.py` lee sus contratos, aplica las reglas y registra hash y versión. Ver `docs/Hito_7.md` para pruebas, límites, ejemplos y evidencia. El precontrol se ejecuta antes del webhook desde GitHub Actions; no equivale a carga nativa en los prompts de n8n.
