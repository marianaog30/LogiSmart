# Declaración de uso de IA y recursos

Proyecto individual de Mariana Orozco. Se utilizó asistencia de ChatGPT/Codex para desarrollar, revisar y documentar HTML/JavaScript, scripts de validación, configuración n8n, prompts, skills, loops, análisis de costos y organización de evidencias. Mariana configuró credenciales en servicios y ejecutó decisiones humanas de prueba. OpenAI opera como proveedor de modelos de los especialistas; ElevenLabs ofrece interfaz de voz/texto. La asistencia no sustituye la responsabilidad de comprender, explicar y verificar el proyecto.

El consumo completo de prompts de desarrollo no se dispone por llamada; no se inventa ni se valora el tiempo humano. El experimento de optimización medido se registra separado del resto no medido.

Widget logístico: HTML/CSS/JavaScript específico del proyecto, sin mapas/fotografías de terceros. Tipografía Times New Roman o sustitución serif disponible en el equipo; no se redistribuyen archivos de fuente. Widget ElevenLabs y GitHub Actions se usan mediante sus mecanismos oficiales; revisar términos/licencias de cada servicio. Python y Node se requieren como entorno, no se empaquetan sus binarios. No se atribuye una licencia de código abierto a todo el repositorio sin decisión expresa de su autora. La guía de la Dra. Elda C. Morales se cita como consigna, no se redistribuye dentro del sitio ni del ZIP.
